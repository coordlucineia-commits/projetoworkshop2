# Design System Overview

# Design System Overview — FORGEE Academy (Cian Edition)

## 1. Concept and Style
A high-impact, performance-driven visual system that blends fitness intensity with digital precision. The aesthetic is built on contrast, energy, and control, combining dark environments with vibrant highlights to create a sense of movement, strength, and transformation. The system balances aggressive visual energy with structured clarity, ensuring usability is never compromised.

**Keywords:** high-contrast, kinetic, bold, minimal-dark, performance-driven, futuristic, cyber-aqua

---

## 2. Color System

### Primitive Colors

#### Neutral Base (Dark-first)
- Gray 900: #0A0A0A
- Gray 800: #121212
- Gray 700: #1C1C1C
- Gray 600: #2A2A2A
- Gray 500: #3A3A3A
- Gray 400: #6B6B6B
- Gray 300: #9A9A9A
- Gray 200: #CFCFCF
- Gray 100: #F5F5F5

#### Core Colors (Cian Scale)
- Cian 500 (Primary Core): #00F9E4
- Cian 600 (Deep Accent): #00C4B3
- Cian 400 (Glow Accent): #33FFEE
- Cian 300 (Soft Glow): #66FFF2
- Cian 700 (Dark Accent): #00998A

#### Support Colors
- White: #FFFFFF
- Black: #090909

---

### Semantic Colors

**Primary**
- #00F9E4  
Used for primary actions, highlights, and key interactive elements.

**Secondary**
- #1C1C1C / #2A2A2A  
Used for surfaces, containers, and layout structure.

**Accent**
- #33FFEE  
Used for hover states, glow effects, and emphasis.

**Success**
- #00F9E4  
Cian também pode indicar sucesso para manter coerência visual.  
Alternativo: #22C55E (evitar se possível).

**Warning**
- #F59E0B  
Used for alerts and attention states.

**Error**
- #EF4444  
Used for critical feedback (única exceção ao cian).

**Usage Principle**
Color is used strategically, not decoratively. Cian acts as a signal, not a background default. Most of the interface remains neutral to amplify emphasis.

---

## 3. Typography

### Style
- Modern neo-grotesk sans-serif
- Strong geometric influence
- Designed for clarity under high contrast

### Hierarchy

**H1**
- Large, bold, uppercase
- Tight line-height
- Used for impact statements

**H2**
- Bold, slightly reduced scale

**H3**
- Medium weight

**Body**
- Regular weight
- High readability on dark backgrounds

**Caption**
- Small size
- Medium contrast (Gray 300–400)

### Weight Distribution
- Bold (700–800) for hierarchy
- Regular (400–500) for readability
- Minimal use of light weights

### Spacing
- Slightly tight tracking for headlines
- Balanced spacing for body text

---

## 4. Spacing and Layout

### Spacing Scale
- Base unit: 8pt
- Scale: 4 / 8 / 16 / 24 / 32 / 48 / 64 / 96

### Layout Density
- Balanced to compact
- High information clarity without clutter

### Grid System
- 12-column grid
- Generous horizontal margins
- Consistent vertical rhythm

### Principles
- Strong alignment
- Predictable spacing rhythm
- Separation via spacing, not borders

---

## 5. Shapes and UI Language

### Border Radius
- 0–6px (sharp to subtle)
- Pill shapes for interactive elements (buttons, tags)

### Stroke Usage
- Minimal
- 1px subtle contrast (Gray 600–700)

### Component Style
- Flat base with selective elevation
- Emphasis through contrast, not layering

### Interaction Feel
- Precise, responsive, controlled
- Micro-interactions reinforce performance perception

---

## 6. Visual Details

### Shadows
- Soft, low-opacity
- Used sparingly for elevation

### Borders
- Subtle or invisible
- Used only when necessary

### Effects
- Cian glow: #00F9E4 with blur
- Gradients:
  - #0A0A0A → #00F9E4
  - #1C1C1C → #00C4B3
- Light bloom on focal elements

### Imagery Integration
- High contrast
- Subjects isolated with strong lighting
- Minimal backgrounds
- Cian color grading applied in highlights

---

## 7. Contrast and Accessibility

### Contrast Level
- High contrast by default

### Readability
- Light text on dark surfaces
- WCAG-compliant contrast ratios

### Hierarchy Strategy
- Cian = ação / destaque principal
- White = conteúdo principal
- Gray = informação secundária

### Accessibility Principles
- Do not rely only on color
- Maintain hierarchy via size and weight
- Ensure visible hover and focus states

### Cian Contrast Reference
- #00F9E4 on #0A0A0A → ~12:1 (excelente)
- #00C4B3 on #1C1C1C → ~8:1 (muito bom)
- Evitar cian claro sobre cinza médio

---

## Final Notes

- The system is **intensity-driven but controlled**
- Visual energy comes from **contrast and restraint**
- Red is **strategic, not dominant**
- Every element should feel **intentional, fast, and precise**
- Prioritize **clarity, hierarchy, and performance perception** over decoration
